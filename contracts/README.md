# API contract

`openapi.yaml` is the source of truth. Edit it first, run `npm run generate`, review both generated directories, and include them in the same commit. Never edit generated files manually.

Phase 0 exposes only public `GET /v1/health`, returning `{ "status": "ok" }`. Startup checks the database once; health describes process liveness, not ongoing database readiness. Domain and auth endpoints arrive in Phase 1.

Go transport types and strict server routing are generated by oapi-codegen. TypeScript declarations are generated by openapi-typescript and consumed by openapi-fetch. Application and storage models remain separate from generated API models.

Every future collection uses opaque cursor pagination: default limit 50, maximum 100, and a typed response containing `items`, `count`, `nextCursor`, and `hasMore`. `count` describes the current page. Use deterministic ordering with a stable unique tie-breaker; do not promise total counts or expose cursor internals.

Specifications are added only with a concrete supported variant. Use `oneOf` with an explicit `type` discriminator mapping and typed `data`. A new variant must update the contract, generated code, backend models/validation/mapping, frontend rendering/editing, and tests together. No arbitrary JSON fallback or placeholder variant is part of Phase 0.
